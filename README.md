# 📚 Book Vibe

> **Discover your next great read from our handpicked recommendations, bestsellers, and timeless classics.**

## ✨ About The Project

**Book Vibe** is a modern and fully responsive web application built for book lovers. It allows users to explore a rich collection of books, view detailed information, and manage their personal reading list (**Read Books**) and **Wishlist** seamlessly with persistent storage using `localStorage`.

---

## 🚀 Key Features

* **📖 Comprehensive Book Catalog:** Browse through a curated list of popular fiction, classics, and fantasy books.
* **🔍 Detailed Book View:** Inspect individual book descriptions, ratings, categories, and publication details.
* **✅ Read & Wishlist Management:** Add books to your "Read" list or "Wishlist" with instant toast notifications.
* **💾 Persistent Storage:** Integrated with `localStorage` so your saved books and lists remain intact even after page refreshes.
* **🎨 Modern UI/UX:** Styled elegantly using [Tailwind CSS](https://tailwindcss.com/) and [DaisyUI](https://daisyui.com/) with a clean, responsive layout.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://react.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
* **Notifications:** React Toastify
* **Language:** TypeScript / JavaScript
